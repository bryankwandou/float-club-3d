# float club. — Scroll-Driven 3D Pool Ring & Water Caustics

Interactive real-time Three.js + GLSL Voronoi pool caustics experience with a 3D striped vinyl inflatable ring, instanced surface water droplets, refractive pool floor shadow, and 6 scroll-scrubbed chapters.

## Stack
- React 19 + TypeScript + Vite
- Three.js WebGL + custom GLSL Voronoi & dual-wave water caustics shader
- 6-chapter smooth scroll-scrubbed camera choreography
- Tailwind CSS v4 design tokens
